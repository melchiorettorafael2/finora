Api Back to front (Back for front)

- Api única especifica responsável por atender a aplicação web
- Aplicação Web (Angular) -> resquest -> (API Back for front) quem serve as infos para aplicação web 

Ex:

Api Emitir Notas Fiscais -> NotaFiscalController -> /notas-fiscais (endpoint) -> 
* POST(SALVAR) */notas-fiscais
* GET/:ID(Buscar por ID) */notas-fiscais/:id
* PUT/:ID(Atualizar) */notas-fiscais/:id
* /fornecedores */notas-fiscais/fornecedores
* /unidades-gestoras */notas-fiscais/fornecedores/unidades-gestoras

* Cada tela tem o seu próprio controller

 API Comum       |  API Back to Front

-----------------|-------------------
